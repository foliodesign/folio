# Contributing

Thanks for your interest in Folio. The source is open so you can read it, learn from it and build it yourself.

## Pull requests

Folio does not accept outside pull requests for now. Pull requests are closed without review. This keeps the project small enough for one maintainer and keeps the ownership of the code clear. This may change later.

## Issues

Bug reports and feature ideas are welcome as [issues](../../issues/new/choose).

- Search existing issues first.
- For a bug, include your iPad model, iPadOS version, Folio version and exact steps.
- Use a design you own. Never post private Figma links, client designs, account details, credentials or device identifiers.
- Suspected security problem? Don't open an issue. Follow [SECURITY.md](SECURITY.md).

For help using the app, see the [user guides](https://foliodesign.app/getting-started) or email [support@foliodesign.app](mailto:support@foliodesign.app).

## Forks

The code is under [Apache-2.0](LICENSE), so you may fork it. The Folio name and icon are not covered by the license: a fork that you distribute needs its own name, icon, bundle IDs and signing. Follow Apple's and Figma's terms for anything you publish.

## Conduct

Follow the [code of conduct](CODE_OF_CONDUCT.md).
