Folio memory lab

Offline allocation experiments inspired by the description of WebKit bug 268816. Retained Uint8Array chunks and a separate WASM Memory.grow ramp. No third-party test code.

Each step is saved natively before allocation and after success. A termination gives a lower bound, not an exact memory ceiling. Reload releases this run's allocations. Simulator results are smoke tests only. 

Ready. Default cap 256 MiB; raise it explicitly for a device ceiling test.
